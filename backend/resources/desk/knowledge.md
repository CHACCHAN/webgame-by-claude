TOUGE NOCTURNE（朧峠夜想曲）: ブラウザで動く3Dレースゲーム。夜の峠を下るダウンヒルが主役。インストール不要、PC・スマホ（横向き）対応。峠と人物は架空。

## モード（メインメニュー）
- タイムアタック: 一人で走り、自己ベスト・メダル（金銀銅。コースと車両ごとに基準タイム）・オンラインランキングを狙う。
- ライバルバトル: コースごとに3人（ROOKIE / LOCAL ACE / LEGEND）と1対1。先にゴールした方の勝ち。ライバルは進路をふさいだりクラクションを鳴らすことがある。
- ゴーストバトル: ランキング上位者や自己ベストの走りを半透明の車で再現し、それを追う。
- オンライン対戦: 最大5人。ルームを作りルームコードを友達に伝える。全員の読み込みが終わり、参加者が「準備完了」を押すとホストが開始できる。コースと時間帯・天候はホストがルーム内で変更できる（「変更」ボタン、X・C キー。リザルトの「コースを変えて走る」でも可）。コースを変えると全員が読み込み直し、準備完了は取り消される。読み込み中のメンバーは一覧に表示され、長く終わらない・切断したメンバーはホストが「外す」で外せる（同じコードで再参加可）。
- ほかに 車両一覧 / ランキング / 設定 / 操作方法 / ABOUT（このゲームについて・AI窓口）。
- レースまでの順: モード → コース → 時間帯・天候 → 車両 → AT/MT →（ライバル選択）→ レース。

## コース
- 朧峠（OBORO PASS）: 港町の夜景を見下ろす4連続ヘアピン、ロックシェッド、橋。王道の峠。
- 霧降湖（KIRIFURI LAKESIDE）: 稜線から湖畔へ。路面が湿っていて滑りやすい。
- 天狼スカイライン（TENROU SKYLINE）: 稜線の高速区間から七曲りのヘアピン。グリップの高い新しい舗装。
- アウトバーン（AUTOBAHN）: 約8kmの3車線高速道路。全開で走る。対向車線に車が走る。
- 時間帯・天候: 深夜・晴れ / 深夜・雨 / 夜明け。雨はタイヤのグリップが約2割落ちる。

## 車両
- 車: SPRINTER TRUENO AE86、SILVIA spec-R (S15)、RX-7 (FD3S)、SUPRA RZ (JZA80)、IMPREZA WRX STI、SKYLINE GT-R (BNR34)、CYBERTRUCK、YANGWANG U9 Xtreme（後の2台は電気自動車で変速なし）。
- バイク: NSR250R、Ninja H2、GSX1300R 隼。
- ネタ枠: 電車（E231系、E235系、京急新1000形、東武30000系、新幹線E5系、リニアL0系。3両編成で走る）、ゴキブリ（最速）。電車とゴキブリも変速なし。
- 車両選択では種類タブ、実測値（0-100km/h、最高速、旋回G）のバー、並べ替え、お気に入り、色（電車は路線カラー）を選べる。

## 操作
- キーボード: アクセル W/↑、ブレーキ・バック S/↓、ステア A D/← →、サイドブレーキ Space、シフト E/Q（MT時）、カメラ切替 C、コースに復帰 R、クラクション H、ポーズ Esc/P、全画面 F。オンライン対戦中は N で通信状態。
- ゲームパッド: アクセル RT/A、ブレーキ LT/X、ステア 左スティック、サイドブレーキ B/RB、シフト Y/LB、カメラ 十字キー上、復帰 Back、クラクション 右スティック押し込み、ポーズ Start。
- スマホ: 画面のボタン（左下 ◀ ▶、右下 アクセル・ブレーキ・サイド、右上 CAM・復帰・II）。横向きで遊ぶ。タイトルをタップすると全画面になる。
- メニュー: 矢印キー/十字キーで選択、Enter/A で決定、Esc/B で戻る。

## 速く走るコツ
- コーナーの手前でまっすぐのうちに減速し、出口が見えたらアクセル全開（スローイン・ファストアウト）。
- タイムを狙うなら滑らせすぎない。ドリフトは角度をつけるほど速度を失う。
- ドリフトのきっかけ: サイドブレーキを一瞬だけ引く / ブレーキを短く踏んで離しながら大きく切る / コーナー中にアクセルを一度戻して踏み直す。向きが変わったら逆ハンドルとアクセルで角度を保ち、出口でステアを戻す。アクセルを踏んだまま曲がるだけでは滑らない。
- 壁に当たると大きく失速する。コースアウトや横転は R で復帰。
- 設定の「運転アシスト」（オフ/標準/強）はカウンターステア補助とスピン防止。「コーナー予告」は急カーブの手前で標識と警告音。
- ゴースト表示（タイムアタック）で自己ベストの自分と走るとラインを比べられる。MTは高回転を保てるが、まずはATで十分。

## 設定と動作が重いとき
- グラフィック品質（低/中/高/最高。PCの初期値は高、スマホは低。一部は再読み込み後に反映）、解像度スケール（50〜100%）、アップスケーリング（低い解像度で描いて拡大。描画解像度とシャープネスを選べる）、描画方式、全画面表示、FPS表示、UIアニメーション、音量（マスター/効果音/音楽/雨音）。
- 重い・カクつくとき: グラフィック品質を下げる → 解像度スケールを下げる、またはアップスケーリングをオン。目標は1080p/60fps。ほかのタブや録画ソフトを閉じる。
- 描画方式: 自動（WebGPUが使えればWebGPU、だめならWebGL 2に自動で切り替え）/ WebGPU / WebGL 2。画面が真っ黒・止まる・乱れるときは再読み込みし、直らなければ描画方式を WebGL 2 にして再読み込み。ブラウザとGPUドライバの更新も有効。WebGPU は新しい Chrome や Edge などで使える。
- 音が出ない: ブラウザの決まりで最初のクリック/タップまで音は鳴らない。設定の音量と、ブラウザのタブのミュートを確認。
- 雨の音が大きい: 設定のサウンド「雨音」で雨の音だけを下げられる（初期値100%、0%で雨音なし）。

## ライバルの声とAI
- ライバルのセリフは言語モデルが作る（設定「ライバルAI」。オフや通信できないときはゲーム内蔵のセリフとルール）。
- 「ライバルの声」: セリフを音声で喋らせる。音声合成モデル（約400MB）を一度だけ取得してブラウザに保存し、GPU（WebGPU）で動かす。WebGPUで描画していないとき（描画方式がWebGL 2）は使えず、文字だけになる。設定「音声モデルのデータ」で削除できる。

## 記録とアカウント
- ゲスト: 記録を残すたびに名前を入力する。ゲストの自己ベストやメダルはページを閉じる・再読み込みすると端末には残らない（ランキングに送った記録は残る）。
- メンバー: メインメニューの LOGIN（表示されている場合）からログインすると、ベストタイム・メダル・ライバル戦績・お気に入りがアカウントに保存され、どの端末でも続きから遊べる。ログイン直前のゲストの記録は引き継がれる。
- ランキングはコースごと。車両で絞り込める。

## この窓口について
- 窓口はプレイヤーの画面・記録・アカウントを見ることも、ゲームやサーバーを操作することもできない。
- 不具合の報告・要望・感想は開発者に届く（受付番号が出る）。返信はここには届かない。AIを使わず「フォームで送る」こともできる。
- 個人情報（本名、連絡先、パスワード）は書かないよう案内する。
